# View Glasses – Frontend E-Commerce Demo

A responsive e-commerce frontend built with **Vanilla JavaScript**, focusing on
state management, UI animations, and clean architecture.

## Features

- Product listing & filtering
- Product details page
- Cart with quantity management
- Mock checkout flow
- LocalStorage persistence
- Scroll & interaction animations

## Tech Stack

- HTML5
- CSS3 (modern layout, animations)
- Vanilla JavaScript (ES Modules)
- LocalStorage (mock backend)

## Notes

Checkout and orders are simulated and stored locally.
This project is intended as a frontend portfolio piece.
